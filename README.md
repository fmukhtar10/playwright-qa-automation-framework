# Playwright QA Automation Framework

A sample test automation framework built with **Playwright and TypeScript**, demonstrating maintainable automation practices, Page Object Model (POM), functional testing, reporting, and CI/CD integration.

## Key Features

- Playwright with TypeScript
- Page Object Model (POM)
- Automated functional test scenarios
- Cross-browser testing configuration
- HTML test reports
- GitHub Actions CI/CD integration

## Technology Stack

- Playwright
- TypeScript
- Node.js
- GitHub Actions

## Getting Started

Install dependencies:

```bash
npm install
npx playwright install
```

Run tests:

```bash
npx playwright test
```

View the HTML report:

```bash
npx playwright show-report
```

## Purpose

This repository demonstrates practical test automation framework design, test organization, and CI/CD integration for software quality engineering.
